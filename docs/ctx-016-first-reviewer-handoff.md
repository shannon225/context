## Intended data flow to verify

`ContextWorkingLibraryPreparer` reads unique target precursor metadata from the source library, requests exact modified-sequence/charge target and decoy spectra through unchanged Encyclopedia/JChronologer APIs, and writes a run-local working library plus a reasoned prediction report. Context's copied `EncyclopediaTwo` selects mapped predicted, shuffled fallback, or target-only candidates using the unchanged 6.9.23 strategy. Its scoring task optionally records pre-trim candidates, then `trim(1)` selects the peak-group winner. `SearchPairSidecar` joins that winner's existing feature `id` to target/decoy keys; `ContextFeatureScorer` validates cache identity and partitions winners by their **search target's** modified sequence and charge. Background rows train the confidence model; reference rows receive that model. `TargetedBootstrapper` writes a separate empirical assay-entrapment relation. The approved defaults are NCE 27, reference charge 2, and DIA NCE adjustment on.
