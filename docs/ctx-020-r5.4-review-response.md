## Finding 4 — agree with the correction, not with a causal sensitivity claim

- **Processing scans:** the previous assay factory reloaded and merged scans at the precursor m/z, while background uses the stripe set passed by the processing loop. This can change scan spacing, the local window, correlations and the E-value score population. Reuse that passed stripe set and precursor map (`ContextEncyclopediaScoringFactory.java:63`). The completion path loads at the selected processing-range midpoint and sorts scans exactly as background does (`:127`). It no longer reloads MS1 once per searched assay row. Range selection uses the same natural range ordering as the search loop. This matches the background API path; it does not promise that the underlying midpoint API excludes every physically overlapping acquisition window.
- **Local window length:** removed the assay-only `+1` (`EncyclopediaTwoPointOneScoringTask.java:249`). The existing `max(1, ...)` still protects single-scan cases. The production full-gradient path now follows the existing background calculation.
- **Zero-intensity fragments:** removed the assay exception to the positive-total chromatogram filter (`:263`). The actual dependency/scorer tests show the approved weak fallback still produces finite candidates for 1/2/3/9/25 scans, 1–3 fragments, zero signal and absent MS1. Do not infer that lack of signal makes the peptide confidently identified.
- **Missing MS1:** retained and documented the packet-index guards (`:310`). Empty precursor maps can return an empty packet; a background fixture without MS1 reproduced the index error during test construction. The assay-only guards preserve the approved no-MS1 behavior. With a normal precursor packet, assay/background feature arrays compare exactly.
- **Second pass:** skip recomputation when every scan already lies inside the effective assay range (`:201`). Restricted-window tests remain valid historical coverage; the production full-gradient calculation is not repeated.
- **Additional parity point:** completion loaded target and mapped-decoy spectra with `useSqrt=false`, unlike the background loop. It now uses `EncyclopediaTwo.useSqrt` consistently. The completion regression checks the supplied spectrum against the dependency's lookup with that setting.
- **Cache:** run identity advances from `assay-full-gradient-scoring-v2` to `v3`. Shared working-library and prediction identities are not changed. Do not reuse old per-run assay features for judging the fix.

For an overlap, a searched assay candidate uses the first processing stripe set dispatched by the existing loop, without another competitive chance. Completion uses a containing range with a finite positive duty cycle. Empty stripe dispatch does not mark a row completed, so a later valid range/completion can still score it. Existing sparse-range assay handling, full-gradient scope, target/decoy identities and winner trimming remain unchanged. Duplicate assay-row policy and the other round-2 findings are not addressed here.
